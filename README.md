# Jaishree Kushwaha — Professional Dynamic Portfolio

## Included
- User-provided profile photo
- User-provided resume PDF
- Responsive modern UI
- Font Awesome icons throughout the site
- Animated typing headline
- Scroll reveal animations
- Active navigation while scrolling
- Reading progress bar
- Dark/light theme
- Project filters
- 3D photo hover effect
- GitHub + LinkedIn + Email + Phone links
- Resume download

## Run
Open `index.html` directly or use VS Code + Live Server.

## LinkedIn
The portfolio uses the exact LinkedIn URL supplied by the user:
https://www.linkedin.com/feed/

For a recruiter-facing profile button, a public profile URL in the form
https://www.linkedin.com/in/your-custom-url
is generally better. LinkedIn documents that public profile URLs use the /in/ format.

## GitHub Pages
Upload the contents to a public GitHub repository, keep index.html in the root,
then enable Settings → Pages → Deploy from branch → main → /root.
